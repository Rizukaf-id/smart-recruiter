# Smart Recruiter AI

Aplikasi HR Tech berbasis AI untuk melakukan screening CV otomatis menggunakan LLM (Llama-3).

## Live Demo
[Klik disini untuk mencoba aplikasi](https://smart-recruiter-aqua-sun.reflex.run/)

## Tech Stack
- **Frontend & Backend:** Python (Reflex Framework)
- **AI Engine:** LangChain + Groq (Llama-3 8B)
- **Data Parsing:** PyPDF & Pydantic
- **UI:** Reflex (Radix Theme)

## Features
- **Automated Screening:** Menganalisa kecocokan CV dengan Job Description.
- **Scoring System:** Memberikan skor 0-100 secara objektif.
- **Pros & Cons Analysis:** Menjabarkan kelebihan dan kekurangan kandidat.
- **Modern UI:** Dark mode, glassmorphism navbar, dan responsive grid.
